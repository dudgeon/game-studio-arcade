# teti on the cabinet: where every file comes from

Upstream: [TitanPlayz100/teti](https://github.com/TitanPlayz100/teti), commit `1de7944ecee0a9e0420349f3da190a385f52a227` (2026-06-03), MIT (`LICENSE`). Licences were checked on 2026-11-11 (D231, D233).

| Files | Origin | Licence |
|---|---|---|
| `play/src/**`, `play/index.html`, `play/styles/*.css` | teti upstream, changed for the cabinet (every change is marked `cabinet:`; `git log guests/teti` shows them against the unmodified import) | MIT, © 2024 TitanPlayz |
| `play/src/cabinet.js`, `tools/make-assets.mjs` | this repo | this repo's |
| `play/assets/sfx/*.wav`, `play/assets/music/brick-parade.wav`, `play/assets/skins/cabinet.png`, `play/assets/particle.png`, `play/assets/icons/*.svg` | generated by `tools/make-assets.mjs` (synthesised sounds, an original tune, drawn shapes) | this repo's |

**Not copied from upstream:**
- `assets/sfx`: TETR.IO's sounds;
- `assets/songs`: commercial Touhou arrangements;
- `assets/skins`: TETR.IO and Jstris look-alikes from a third party, licence unknown;
- `assets/icons`: provenance unknown;
- `assets/peakpx.jpg`: a wallpaper-site image;
- `assets/particle.png` and `titanicon.ico`;
- the Tauri desktop wrapper.

**Tetris name and look:** no Tetris name. The piece colours follow the common guideline style (cyan I, yellow O, purple T and so on); the skin itself is ours.

**Regenerating the assets:** `node guests/teti/tools/make-assets.mjs`. The same script gives the same files.
